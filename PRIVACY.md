# Privacy

Desktop Icons Toggle changes Explorer's desktop-icon visibility. It does not delete files, hide application windows, capture screenshots, read documents, or record keystrokes. The hotkey uses Windows RegisterHotKey, not a keyboard-monitoring hook.

The standalone app stores local status and error information in %LOCALAPPDATA%\DesktopIconsToggle. These files are not sent anywhere. The Windhawk version stores no app data of its own.
There are no accounts, telemetry, network listeners, downloads, or update checks in this project's code. Windhawk and GitHub have their own separate network behavior and privacy policies.

No personal settings or desktop screenshots are included in public release archives.
