# Security

Run as a normal Windows user. Administrator privileges are not required.
There is no network listener, telemetry, account system, update downloader, or remote command interface.
This is a small community project, not independently security-certified software.

Do not post account tokens, personal paths, settings files, or unredacted screenshots in public issues.
If GitHub private vulnerability reporting is enabled, use the repository's Security tab to report a vulnerability privately. Do not disclose an exploitable vulnerability or private data in a public issue; if private reporting is unavailable, first ask the maintainer for a private reporting channel without technical exploit details.

Local Windows account permissions protect settings. These tools cannot protect a PC already controlled by malware or an administrator. Same-user processes are not treated as a security boundary.
Release executables are unsigned unless a release explicitly says otherwise. Hashes verify that a download matches the published release; they are not a substitute for trusting the publisher. Do not disable Windows security protections to run a download.
